# Ementa Curricular: Formação em Análise de Dados e Business Intelligence

### 1. Introdução à Análise de Dados e BI
*Foco nos conceitos iniciais de Business Intelligence*, versionamento de código e primeiros passos com ferramentas de análise.
* **Cursos:** *Introdução ao Excel e Power BI Dashboards*; *Fundamentos de Business Intelligence (BI);* Introdução a Análise de Dados com SQL; Git e GitHub (Primeiros Passos e Configuração); Desafios de Projetos (Criação de Portfólio).
* **Projetos Práticos:** Contribuindo em um Projeto Open Source no GitHub.

### 2. Explorando Bancos Relacionais e Consultas SQL
Aprofundamento em banco de dados, desde a criação de consultas básicas até agrupamentos, junções e modelagem lógica avançada.
* **Cursos:** Primeiros Passos com SQL; Explorando Queries com SQL; Criando Queries com Funções e Cláusulas de Agrupamentos; Agrupando Registros e Tabelas com Join Statement; Desafios de Código (Lógica e Pensamento Computacional).
* **Projetos Práticos:** Construindo seu Primeiro Projeto Lógico de Banco de Dados; Construa um Projeto Lógico de Banco de Dados do Zero.
* **Desafios de Código:** Associando Comandos SQL com Lógica de Programação.

### 3. Análise de Dados com Excel e Copilot
Uso avançado do Microsoft Excel integrado com Inteligência Artificial (Copilot) e Power Query para automação e ETL.
* **Cursos:** Introdução ao Excel 365; Trabalhando com Microsoft Copilot; Utilizando Microsoft Copilot para escrever consultas SQL; Criando um Processo de ETL com Excel e Power Query; Analisando Bases de Dados com Excel e Copilot.
* **Projetos Práticos:** Criando um Dashboard de Vendas do Xbox com Excel.
* **Desafios de Código:** Associando Fórmulas Excel com Lógica de Programação.

### 4. Fundamentos e Visualização de Dados com Power BI
Introdução à ferramenta da Microsoft, focando em extração teórica, métricas e criação de visuais e relatórios gerenciais interativos.
* **Cursos:** *Fundamentos Teóricos Sobre ETL*; Primeiros Passos com Power BI; *Trabalhando com Visuais no Power BI*; *Fundamentos de BI (KPIs e Métricas)*; Criando Dashboards Interativos com Power BI.
* **Projetos Práticos:** Analisando dados de um Dashboard de Vendas no Power BI; Criando Um Relatório Gerencial de Vendas com Power BI.

### 5. Processamento e Modelagem de Dados no Power BI
Etapa técnica de conexão com fontes de dados, tratamento, limpeza e construção de modelos dimensionais (Star Schema) e uso de linguagem DAX.
* **Cursos:** *Coleta e Extração de Dados*; Limpeza e Transformação de Dados; *Fundamentos de Modelagem Dimensional*; *Modelagem de Dados no Power BI*; Primeiros passos com DAX e Cálculos; *Otimização de Modelo de Dados com Foco em Desempenho*.
* **Projetos Práticos:** Criando um Dashboard corporativo com integração com MySQL e Azure; Dashboard de Vendas com Power BI utilizando Star Schema; Modelando um Dashboard de E-commerce com Power BI Utilizando Fórmulas DAX.

### 6. Data Analytics, Storytelling e Governança no Power BI
Finalização da trilha com foco em *experiência do usuário*, contação de histórias com dados e administração de ambientes de trabalho no Power BI Service.
* **Cursos:** Relatórios & Experiência do Usuário no Power BI; Explorando Recursos para criar Storytelling dos dados; *Fundamentos de Data Analytics*; Gerenciamento de Workspaces; Gerenciamento de Datasets.
* **Projetos Práticos:** Criando um Dashboard Gerencial para Tomada de Decisões; Criando um Relatório Vendas e Lucros com Data Analytics; Criando Relatórios Dinâmicos com o uso de Parâmetros no Power BI.
